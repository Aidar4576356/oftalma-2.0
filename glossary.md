# Глоссарий

Единый алфавитный список терминов по всем законспектированным главам. Формат: **Термин / АББРЕВИАТУРА** — определение, номер главы первого появления.

---

**ACCEPT** — сервисный примитив: сервер принимает входящее соединение от объекта того же уровня. _(гл. 1)_

**ad hoc сеть (беспроводная)** — режим, в котором клиенты 802.11 общаются напрямую друг с другом без точки доступа. _(гл. 1)_

**ALOHA** — ранняя беспроводная сеть (Гавайи), от которой унаследован принцип случайной паузы перед повторной передачей при коллизии; предок CSMA. _(гл. 1)_

**AP / точка доступа (access point)** — устройство (беспроводной маршрутизатор/базовая станция), через которое проходит связь клиентов беспроводной ЛВС и Интернета. _(гл. 1)_

**ARPA** — Advanced Research Projects Agency, Управление перспективного планирования научно-исследовательских работ Минобороны США; инициатор создания ARPANET. _(гл. 1)_

**ARPANET** — первая крупная сеть с коммутацией пакетов, построенная по заказу ARPA (США), предшественник Интернета. _(гл. 1)_

**B2B / B2C / C2C / G2C** — формы электронной коммерции: коммерсант коммерсанту, коммерсант клиенту, клиент клиенту, государство клиенту (см. также P2P). _(гл. 1)_

**CONNECT** — сервисный примитив: клиент устанавливает соединение с ожидающим объектом того же уровня. _(гл. 1)_

**CSMA (Carrier Sense Multiple Access)** — множественный доступ с прослушиванием несущей: устройство слушает канал и выжидает случайную паузу перед передачей, чтобы избежать столкновений. _(гл. 1)_

**DISCONNECT** — сервисный примитив: разрыв установленного соединения. _(гл. 1)_

**DSL / DSLAM** — Digital Subscriber Line, цифровая передача данных по телефонной линии; DSLAM (Digital Subscriber Line Access Multiplexer) — узел провайдера, преобразующий сигналы линии в пакеты. _(гл. 1)_

**Ethernet / IEEE 802.3** — наиболее распространённый стандарт проводной ЛВС; топология на основе коммутатора (коммутируемый Ethernet) или общего кабеля (классический Ethernet). _(гл. 1)_

**GPS (Global Positioning System)** — система глобального позиционирования, определение местоположения устройства по спутниковым сигналам. _(гл. 1)_

**GSM** — Global System for Mobile Communications, наиболее распространённая система мобильной связи 2-го поколения (2G), с 1991 года. _(гл. 1)_

**ICMP (Internet Control Message Protocol)** — вспомогательный протокол межсетевого уровня TCP/IP для передачи диагностической/управляющей информации (например, об ошибках маршрутизации). _(гл. 1)_

**IEEE (Institute of Electrical and Electronics Engineers)** — крупнейшая профессиональная организация в мире; комитет 802 разрабатывает стандарты ЛВС (Ethernet, Wi-Fi и др.). _(гл. 1)_

**IETF (Internet Engineering Task Force)** — рабочая группа краткосрочных инженерных задач в структуре стандартизации Интернета, подчинена IAB. _(гл. 1)_

**IAB (Internet Architecture Board)** — совет по архитектуре Интернета, координирует стандарты Интернета (утверждает RFC как стандарты). _(гл. 1)_

**IMP (Interface Message Processor)** — специализированный мини-компьютер, из которых строилась подсеть ARPANET (предок современного маршрутизатора). _(гл. 1)_

**Интерсеть / internetwork** — набор соединённых разнородных сетей; отличать от «Интернет» (конкретная всемирная интерсеть на TCP/IP). _(гл. 1)_

**Интерфейс (между уровнями)** — набор примитивных операций, которые нижний уровень протокольной иерархии предоставляет верхнему; определяется между каждой парой смежных уровней на одной машине. _(гл. 1)_

**Интрасеть** — использование интернет-технологий внутри организации с ограниченным (внутренним) доступом. _(гл. 1)_

**IP (Internet Protocol)** — основной протокол межсетевого уровня TCP/IP, обеспечивает доставку пакетов (дейтаграмм) по сети без установления соединения. _(гл. 1)_

**IPTV (IPTeleVision)** — доставка телевизионного контента поверх IP-сети вместо кабельного/эфирного телевидения. _(гл. 1)_

**ISM-диапазон** — нелицензируемые частотные полосы для промышленного/научного/медицинского применения (Industrial, Scientific, Medical), на которых работает 802.11. _(гл. 1)_

**ISO (International Organization for Standardization)** — международная организация по стандартизации, разработчик модели OSI и множества других стандартов. _(гл. 1)_

**ISP (Internet Service Provider)** — поставщик интернет-услуг, оператор подсети провайдера, соединяющий клиентов с Интернетом. _(гл. 1)_

**ITU / ITU-T / ITU-R / ITU-D** — Международный союз электросвязи и его секторы: T — стандартизация телекоммуникаций, R — радиосвязь, D — развитие ИКТ в странах с ограниченным доступом. _(гл. 1)_

**Клиент** — менее мощная машина (или её пользователь) в клиент-серверной модели, обращающаяся за данными/услугами к серверу. _(гл. 1)_

**Клиент-серверная модель** — архитектура сети, в которой сервер хранит данные/выполняет вычисления, а клиенты обращаются к нему по сети с запросами и получают ответы. _(гл. 1)_

**Коммутатор (switch)** — устройство канального уровня, пересылающее пакеты между подключёнными к нему компьютерами по адресу в пакете; основа топологии коммутируемого Ethernet. _(гл. 1)_

**Коммутация с промежуточной буферизацией** — способ обработки сообщения промежуточным узлом, при котором сообщение принимается полностью, прежде чем пересылается дальше (в противовес сквозной передаче). _(гл. 1)_

**Компьютерная сеть** — набор автономных компьютеров, связанных одной технологией передачи данных. _(гл. 1)_

**ЛВС / LAN (Local Area Network)** — локальная сеть, обычно в пределах здания или территории организации. _(гл. 1)_

**LISTEN** — сервисный примитив: блокировка процесса в ожидании входящего соединения. _(гл. 1)_

**MAN (Metropolitan Area Network)** — муниципальная сеть, охватывающая масштаб города (пример — сеть кабельного телевидения). _(гл. 1)_

**m-commerce (мобильная торговля)** — электронная коммерция через мобильный телефон, оплата через SMS/счёт оператора. _(гл. 1)_

**Многоадресная передача (multicasting)** — отправка пакета определённому подмножеству машин сети. _(гл. 1)_

**NFC (Near Field Communication)** — технология связи малого радиуса действия, позволяющая мобильному телефону работать как RFID-карта для бесконтактной оплаты. _(гл. 1)_

**NIST (National Institute of Standards and Technology)** — американский институт стандартов, подразделение Министерства торговли США. _(гл. 1)_

**OFDM (Orthogonal Frequency Division Multiplexing)** — мультиплексирование с ортогональным частотным разделением сигналов: широкая полоса делится на множество узких поднесущих, по которым параллельно передаются разные биты; используется в 802.11a/g/n и далее. _(гл. 1)_

**OSI (Open Systems Interconnection)** — эталонная семиуровневая модель взаимодействия открытых систем, разработанная ISO. _(гл. 1)_

**P2P (Peer-to-Peer, равноранговая сеть)** — сетевая архитектура без выделенного сервера, где каждый узел равноправен и может быть и клиентом, и сервером (пример протокола — BitTorrent). _(гл. 1)_

**PAN (Personal Area Network)** — персональная сеть в масштабе одного человека (пример — Bluetooth). _(гл. 1)_

**Пакет** — единица данных сетевого уровня; в широком смысле — любое короткое сообщение, передаваемое по сети. _(гл. 1)_

**Примитив (службы)** — операция (аналог системного вызова), которую служба предоставляет пользователю верхнего уровня для получения сервиса. _(гл. 1)_

**Протокол** — набор правил и соглашений, определяющих формат и смысл сообщений, которыми обмениваются равноранговые сущности одного уровня на разных машинах. _(гл. 1)_

**PTT (Postal Telegraph and Telephone administration)** — государственное управление почтово-телеграфной и телефонной связи, исторически распространённая модель регулирования телекоммуникаций вне США. _(гл. 1)_

**RECEIVE** — сервисный примитив: блокировка процесса в ожидании входящего сообщения. _(гл. 1)_

**RFC (Request for Comments)** — технические документы, в виде которых публикуются стандарты и предложения Интернета, пронумерованы хронологически. _(гл. 1)_

**RFID (Radio Frequency Identification)** — радиочастотная идентификация: метка с чипом и антенной, опрашиваемая считывателем на расстоянии; пассивная (без батареи) или активная (со своим питанием); диапазоны — LF, ВЧ (HF), УВЧ (UHF). _(гл. 1)_

**RTP (Real-time Transport Protocol)** — протокол прикладного уровня TCP/IP для доставки мультимедиа реального времени. _(гл. 1)_

**Сенсорная сеть** — сеть автономных узлов-датчиков (температура, вибрация и т.п.), передающих данные по радио с ретрансляцией через соседей к точке сбора. _(гл. 1)_

**Сервер** — мощная машина, хранящая данные/выполняющая вычисления и обслуживающая запросы клиентов в клиент-серверной модели. _(гл. 1)_

**Сеть предприятия (enterprise network)** — локальная сеть, используемая предприятием/организацией. _(гл. 1)_

**SEND** — сервисный примитив: отправка сообщения ожидающему объекту того же уровня. _(гл. 1)_

**SIM-карта (Subscriber Identity Module)** — сменный чип мобильного телефона с идентификатором абонента и данными учётной записи, используется для аутентификации и шифрования. _(гл. 1)_

**Скользящее окно** — см. соответствующую запись в конспекте главы 3 (несущий раздел 3.4).

**SMS (Short Message Service)** — служба коротких текстовых сообщений мобильной связи. _(гл. 1)_

**Служба (сервис)** — набор примитивов (операций), которые уровень предоставляет вышестоящему уровню; определяет, что уровень делает, но не как это реализовано; относится к интерфейсу между уровнями на одной машине (в отличие от протокола). _(гл. 1)_

**Служба без установления соединения** — тип службы, при котором каждое сообщение (пакет) несёт полный адрес назначения и идёт по сети независимо от других сообщений, без предварительной установки соединения (аналог — почта). _(гл. 1)_

**Служба дейтаграмм (дейтаграммная служба)** — ненадёжная служба без установления соединения и без подтверждений (аналог телеграфа). _(гл. 1)_

**Служба запросов и ответов** — служба без установления соединения, в которой отправитель посылает дейтаграмму-запрос и получает дейтаграмму-ответ; типичная реализация клиент-серверного общения. _(гл. 1)_

**Служба с установлением соединения** — тип службы, при котором сначала устанавливается соединение (обмен параметрами), затем идёт передача данных, затем соединение разрывается (аналог — телефонный звонок). _(гл. 1)_

**Сокет (socket)** — программный интерфейс для сетевого программирования, впервые реализован в Berkeley UNIX 4.2BSD для протоколов TCP/IP; лёг в основу примитивов служб (LISTEN/CONNECT/ACCEPT и др.). _(гл. 1)_

**Социальная сеть** — сервис, в котором поток информации управляется отношениями («друзьями»), которые пользователи объявляют друг о друге (пример — Facebook). _(гл. 1)_

**Сквозная передача** — способ обработки сообщения промежуточным узлом, при котором пересылка начинается раньше, чем сообщение получено целиком (в противовес коммутации с промежуточной буферизацией). _(гл. 1)_

**Стек протоколов** — список протоколов, используемых системой, по одному протоколу на уровень. _(гл. 1)_

**TCP (Transmission Control Protocol)** — надёжный протокол транспортного уровня TCP/IP с установлением соединения, доставляющий байтовый поток без ошибок и с сохранением порядка. _(гл. 1)_

**TCP/IP, модель** — четырёхуровневая (в некоторых трактовках — гибридная пятиуровневая) эталонная модель, описывающая протоколы, реально используемые в Интернете; уровни: связь, межсетевой, транспортный, прикладной. _(гл. 1)_

**UDP (User Datagram Protocol)** — ненадёжный протокол транспортного уровня TCP/IP без установления соединения. _(гл. 1)_

**Уровень (слой)** — часть иерархии протоколов сети, предоставляющая службу вышестоящему уровню и скрывающая от него детали своей реализации. _(гл. 1)_

**Уровневая архитектура сети** — набор уровней и протоколов сети (без деталей реализации и спецификации интерфейсов). _(гл. 1)_

**Однонаправленная передача (unicasting)** — передача пакета с ровно одним отправителем и ровно одним получателем. _(гл. 1)_

**VLAN (виртуальная ЛВС)** — логическое разделение одной физической ЛВС на несколько независимых логических сетей через маркировку портов коммутатора. _(гл. 1)_

**VoIP (Voice over IP) / IP-телефония** — передача голосовых вызовов поверх компьютерной сети вместо традиционной телефонной сети. _(гл. 1)_

**VPN (Virtual Private Network)** — виртуальная частная сеть: соединение географически разнесённых узлов через публичную инфраструктуру (обычно Интернет) с иллюзией единой выделенной сети. _(гл. 1)_

**WAN (Wide Area Network)** — глобальная сеть, охватывающая страну или континент. _(гл. 1)_

**W3C (World Wide Web Consortium)** — промышленный консорциум, разрабатывающий веб-стандарты (HTML, веб-безопасность и др.). _(гл. 1)_

**WCDMA / UMTS** — Wideband Code Division Multiple Access / Universal Mobile Telecommunications System — основная система мобильной связи 3-го поколения (3G). _(гл. 1)_

**WEP (Wired Equivalent Privacy)** — первая, впоследствии признанная небезопасной схема шифрования 802.11; заменена на WPA/WPA2. _(гл. 1)_

**Wi-Fi / 802.11** — стандарт IEEE для беспроводных ЛВС. _(гл. 1)_

**WiMAX / 802.16** — стандарт IEEE для беспроводного широкополосного доступа в масштабе города (MAN); ⚠ практически не прижился на рынке. _(гл. 1)_

**Wiki** — веб-сайт, совместно редактируемый сообществом пользователей (пример — Википедия). _(гл. 1)_

**WPA / WPA2 / WPA3 (Wi-Fi Protected Access)** — схемы шифрования и защиты беспроводных сетей 802.11, пришедшие на смену небезопасному WEP. _(гл. 1)_

**Широковещательная передача (broadcasting)** — отправка пакета, который получают и обрабатывают все машины сети. _(гл. 1)_

**Широковещательная сеть** — сеть с единым каналом связи, совместно используемым всеми подключёнными машинами. _(гл. 1)_

**Шлюз (gateway)** — машина, обеспечивающая соединение и необходимый перевод формата между двумя или более сетями; маршрутизатор — шлюз, работающий на сетевом уровне. _(гл. 1)_

**Хост (host)** — компьютер в сети, выполняющий пользовательские программы (приложения), в отличие от узлов подсети (маршрутизаторов). _(гл. 1)_

**Заголовок (header)** — управляющая информация (адреса, порядковые номера, размеры и т.п.), добавляемая уровнем протокола перед данными вышестоящего уровня при инкапсуляции. _(гл. 1)_

**Завершающая последовательность / хвостовик (trailer)** — служебная информация с контрольной суммой, добавляемая канальным уровнем в конец кадра. _(гл. 1)_

**Инкапсуляция** — механизм последовательного «оборачивания» данных верхнего уровня заголовками (и, на канальном уровне, хвостовиком) каждого нижележащего уровня при прохождении вниз по стеку протоколов. _(гл. 1)_

**Маршрутизатор (router)** — специализированный компьютер, соединяющий несколько линий связи и выбирающий выходную линию для дальнейшей пересылки пакета; шлюз сетевого уровня. _(гл. 1)_

**Алгоритм маршрутизации** — метод принятия решения о выборе маршрута между двумя маршрутизаторами, не связанными напрямую (в масштабе всей сети). _(гл. 1)_

**Алгоритм пересылки** — способ, которым конкретный маршрутизатор решает, на какую исходящую линию отправить пришедший пакет. _(гл. 1)_

**Подсеть (subnet)** — в контексте WAN: набор маршрутизаторов и линий связи, принадлежащих одному сетевому оператору, передающий сообщения от хоста к хосту. _(гл. 1)_

**Равноранговые процессы (peer processes)** — объекты одного и того же уровня протокольной иерархии на разных машинах, логически «общающиеся» друг с другом по протоколу этого уровня. _(гл. 1)_

**Равноранговая связь / пиринг (peering)** — соглашение между интернет-провайдерами об обмене трафиком без взаимной оплаты за транзит. _(гл. 1)_

**Распределённая система** — программная система (обычно на основе связующего ПО), построенная поверх компьютерной сети и создающая для пользователя иллюзию единой связной системы. _(гл. 1)_

**Связующее ПО (middleware)** — программный слой над операционной системой, реализующий для пользователя иллюзию единой распределённой системы поверх множества автономных машин. _(гл. 1)_

**Скопление (congestion) / перегрузка сети** — ситуация, когда слишком много узлов одновременно пытаются передать слишком много данных, и сеть не справляется. _(гл. 1)_

**Статистическое мультиплексирование** — динамическое совместное использование пропускной способности по фактической краткосрочной потребности узлов, а не жёсткое закрепление фиксированной доли за каждым. _(гл. 1)_

**Управление потоком** — механизм обратной связи от получателя к отправителю, не позволяющий быстрому отправителю «затопить» данными медленного получателя. _(гл. 1)_

**Качество обслуживания (QoS)** — механизмы, регулирующие конкурирующие требования приложений к сети (задержка, пропускная способность, своевременность доставки). _(гл. 1)_

**4B/5B** — линейный код: каждые 4 входных бита отображаются в 5-битный код так, чтобы не было больше трёх нулей подряд; overhead 25%, неиспользуемые коды несут служебные сигналы физического уровня. _(гл. 2)_

**8B/10B** — симметричный линейный код: 8 входных бит → один из двух взаимодополняющих 10-битных кодов, выбираемый так, чтобы минимизировать накопленный дисбаланс нулей/единиц (неравенство); ограничивает длину серий одинаковых бит для облегчения синхронизации. _(гл. 2)_

**A-закон (A-law)** — стандарт компандирования при импульсно-кодовой модуляции, используемый в Европе и большей части мира (в паре с μ-законом в Северной Америке/Японии), зафиксирован в ITU G.711. _(гл. 2)_

**ADSL / xDSL (Asymmetric Digital Subscriber Line)** — асимметричная цифровая абонентская линия: использует всю физическую полосу местной телефонной линии (не только голосовой диапазон) для передачи данных, с несимметричным распределением полосы между входящим и исходящим потоком. _(гл. 2)_

**AMI (Alternate Mark Inversion) / биполярное кодирование** — симметричный линейный код: логическая 1 передаётся чередующимся +V/−V, логический 0 — нулевым напряжением; телефонное название AMI. _(гл. 2)_

**AMPS (Advanced Mobile Phone System)** — основная аналоговая система мобильной связи первого поколения (1G) в США, 832 дуплексных FDD-канала по 30 кГц. _(гл. 2)_

**ASK (Amplitude Shift Keying)** — амплитудная манипуляция: цифровые символы кодируются разными амплитудами несущей. _(гл. 2)_

**Битрейт** — скорость передачи данных в битах в секунду; равен символьной скорости, умноженной на число бит на символ (не путать с бодрейтом/символьной скоростью). _(гл. 2)_

**Бодрейт / символьная скорость** — скорость, с которой сигнал меняет уровень (символ в секунду); отличается от битрейта, если на символ приходится больше одного бита. _(гл. 2)_

**BPSK (Binary Phase Shift Keying)** — бинарная фазовая манипуляция: два состояния несущей, различающиеся фазой на 180°. _(гл. 2)_

**BSC (Base Station Controller)** — контроллер базовой станции в архитектуре GSM: управляет радиоресурсами сот и обрабатывает передачу обслуживания между ними. _(гл. 2)_

**CDM / CDMA (Code Division Multiplexing / Multiple Access)** — кодовое разделение каналов: узкополосный сигнал каждой станции «размазывается» по широкой полосе с помощью уникальной ортогональной (или псевдослучайной) чип-последовательности; несколько станций делят одну и ту же полосу и время одновременно, различаясь только кодом. _(гл. 2)_

**CDMA2000** — технология 3G, продвинутая компанией Qualcomm, совместимая с американским стандартом 2G IS-95; альтернатива WCDMA/UMTS. _(гл. 2)_

**CMTS (Cable Modem Termination System)** — оконечное устройство кабельного модема на стороне оператора: современный аналог старого распределителя кабельной сети, с высокоскоростным оптическим подключением к провайдеру. _(гл. 2)_

**Дисперсия (световая)** — удлинение (размытие) светового импульса по мере распространения по оптоволокну; компенсируется специальной формой импульса (солитоны). _(гл. 2)_

**Диаграмма созвездия** — графическое представление схемы модуляции: точки на плоскости амплитуда/фаза, каждая соответствует одному символу (например, QAM-16, QAM-64). _(гл. 2)_

**Дисбаланс постоянного тока / симметричный сигнал** — свойство сигнала, у которого положительное и отрицательное напряжение уравновешены даже на коротких интервалах; отсутствие постоянной составляющей важно для каналов с ёмкостной/трансформаторной связью. _(гл. 2)_

**DMT (Discrete MultiTone, дискретная мультитональная модуляция)** — применение OFDM в ADSL: доступный спектр местной линии делится на 256 узких каналов, каждый модулируется отдельно. _(гл. 2)_

**DOCSIS (Data Over Cable Service Interface Specification)** — открытый стандарт кабельных модемов (консорциум CableLabs), обеспечивающий совместимость оборудования разных производителей. _(гл. 2)_

**Дуплекс / полудуплекс / симплекс** — режимы линии связи: дуплекс — одновременная передача в обе стороны, полудуплекс — в обе стороны по очереди, симплекс — только в одну сторону. _(гл. 2)_

**Децибел (дБ)** — логарифмическая единица отношения мощностей: 10·log₁₀(отношение); используется для отношения сигнал/шум и ослабления сигнала. _(гл. 2)_

**EDGE (Enhanced Data rates for GSM Evolution)** — переходная технология «2,5G»: обычный GSM с бо́льшим числом бит на символ и несколькими схемами модуляции/коррекции ошибок для роста скорости передачи данных. _(гл. 2)_

**EPON (Ethernet PON)** — стандарт пассивной оптической сети (IEEE), альтернатива GPON. _(гл. 2)_

**Ёмкость канала** — максимальная скорость передачи данных, достижимая по каналу с заданной полосой и уровнем шума (формула Шеннона). _(гл. 2)_

**FDD (Frequency Division Duplex)** — дуплексный режим с разделением частоты: приём и передача идут на разных, заранее закреплённых частотах. _(гл. 2)_

**FDM (Frequency Division Multiplexing)** — частотное уплотнение: спектр канала делится на полосы частот, каждый пользователь/сигнал получает свою полосу с защитными промежутками между соседними полосами. _(гл. 2)_

**FSK (Frequency Shift Keying)** — частотная манипуляция: цифровые символы кодируются разными частотами («тонами») несущей. _(гл. 2)_

**FTTH (Fiber To The Home)** — «волокно до дома»: замена медной местной линии оптоволокном на всём пути до здания абонента. _(гл. 2)_

**Гармоника** — составляющая ряда Фурье на частоте, кратной основной частоте периодического сигнала. _(гл. 2)_

**GEO (Geostationary Earth Orbit)** — геостационарная орбита (высота 35 800 км, экваториальная): спутник неподвижен относительно поверхности Земли; задержка ≈270 мс в одну сторону. _(гл. 2)_

**Globalstar** — группировка низкоорбитальных спутников (LEO) для голосовой связи, использующая ретрансляцию сигнала по схеме «узкая труба» через наземные концентраторы (в отличие от Iridium). _(гл. 2)_

**GPON (Gigabit PON)** — стандарт пассивной оптической сети (ITU), альтернатива EPON. _(гл. 2)_

**HFC (Hybrid Fiber Coax)** — гибридная оптокоаксиальная сеть: оптоволокно на магистральных участках + коаксиальный кабель на последнем участке до абонента, соединённые оптоузлами. _(гл. 2)_

**Iridium** — группировка низкоорбитальных спутников (LEO, 66 спутников, 6 полярных «ожерелий») для голосовой связи с ретрансляцией сигнала «спутник-спутник» прямо в космосе. _(гл. 2)_

**IXC (InterExchange Carrier)** — оператор междугородной связи в телефонной системе США, обслуживающий звонки между разными LATA; подключается к LEC в точке присутствия (POP). _(гл. 2)_

**Код Грея** — способ отображения битов на символы модуляции так, что соседние символы отличаются только одним битом — снижает число битовых ошибок при шуме. _(гл. 2)_

**Кодек (кодер-декодер)** — устройство на телефонной оконечной станции, оцифровывающее аналоговый голосовой сигнал в PCM-поток и выполняющее обратное преобразование. _(гл. 2)_

**Компандирование** — сжатие динамического диапазона сигнала перед равномерным квантованием и его расширение при восстановлении (μ-закон, A-закон), уменьшает ошибку квантования для слабых сигналов. _(гл. 2)_

**Коммутация каналов** — способ соединения, при котором физический путь между абонентами устанавливается целиком до начала передачи и сохраняется неизменным до конца сеанса связи; противопоставляется коммутации пакетов (несущий раздел 2.6.5; см. также 5.1). _(гл. 2)_

**LATA (Local Access and Transport Area)** — географическая зона телефонной сети США (введены при разделении AT&T в 1984 году), внутри которой звонки обслуживает LEC, а между зонами — IXC. _(гл. 2)_

**LEC (Local Exchange Carrier)** — оператор местной телефонной связи, обслуживающий звонки внутри одной LATA. _(гл. 2)_

**LEO (Low-Earth Orbit)** — низкая орбита спутников связи: короткая задержка (единицы мс) и слабые передатчики, но нужна большая группировка спутников для полного покрытия Земли (примеры — Iridium, Globalstar). _(гл. 2)_

**Линейный код** — схема кодирования битов в сигнал основной полосы частот, спроектированная для эффективного использования полосы, восстановления синхронизации и баланса постоянного тока (NRZ, NRZI, Манчестер, 4B/5B, 8B/10B и др.). _(гл. 2)_

**Манчестерское кодирование** — линейный код, совмещающий сигнал часов и данных через «исключающее или»: переход низкий→высокий в середине битового интервала = 0, высокий→низкий = 1; использовался в классическом Ethernet, вдвое дороже по полосе, чем NRZ. _(гл. 2)_

**Многолучевое затухание (multipath fading)** — подавление сигнала на приёме из-за интерференции прямого луча с его отражениями, пришедшими другим путём и с фазовым сдвигом; характерно для микроволновой и радиосвязи. _(гл. 2)_

**Многомодовое волокно** — оптоволокно с диаметром сердцевины (~50 мкм), достаточным для одновременного распространения света под разными углами (модами); дешевле одномодового, годится для коротких дистанций. _(гл. 2)_

**MEO (Medium-Earth Orbit)** — средневысотная орбита спутников (между поясами Ван Аллена, период обращения ~6 часов); используется в основном для навигации (GPS), а не связи. _(гл. 2)_

**Модем (модулятор-демодулятор)** — устройство, преобразующее поток бит в аналоговый сигнал канала и обратно. _(гл. 2)_

**MSC / MTSO (Mobile Switching Center / Mobile Telephone Switching Office)** — коммутатор мобильных телефонов, назначающий каналы и управляющий передачей обслуживания между сотами. _(гл. 2)_

**Мультиплексирование** — совместное использование одного физического канала несколькими сигналами/пользователями; на физическом уровне — по частоте (FDM), времени (TDM) или коду (CDM) — несущий раздел 2.5; отлично от мультиплексирования портов на транспортном уровне (см. 6.2.5). _(гл. 2)_

**Найквиста предел / теорема Найквиста** — для идеального бесшумного канала с полосой B и V уровнями сигнала максимальная скорость передачи данных = 2B·log₂V бит/с. _(гл. 2)_

**NRZ (Non-Return-to-Zero)** — простейший линейный код: положительное напряжение = 1, отрицательное = 0, сигнал напрямую следует за данными. _(гл. 2)_

**NRZI (Non-Return-to-Zero Inverted)** — линейный код: логическая 1 кодируется переходом уровня, 0 — его отсутствием; используется в USB. _(гл. 2)_

**Оптоузел** — электрооптический преобразователь в гибридной оптокоаксиальной сети (HFC), соединяющий оптический магистральный участок с коаксиальными сегментами. _(гл. 2)_

**Одномодовое волокно** — оптоволокно с диаметром сердцевины, соизмеримым с длиной волны света (8–10 мкм): работает как волновод без множественных мод, дороже многомодового, но годится для больших дистанций/скоростей. _(гл. 2)_

**OFDM (Orthogonal Frequency Division Multiplexing)** — см. запись в глоссарии главы 1; в главе 2 разбирается подробно как часть несущего раздела о мультиплексировании (2.5.3), включая применение в ADSL под именем DMT. _(гл. 2)_

**Отношение сигнал/шум (S/N)** — отношение мощности полезного сигнала к мощности шума в канале, обычно выражается в децибелах; ключевой параметр формулы Шеннона. _(гл. 2)_

**PCM (Pulse Code Modulation, импульсно-кодовая модуляция)** — оцифровка аналогового голосового сигнала: 8000 отсчётов в секунду по 8 бит, несжатый канал — 64 Кбит/с; основа цифровой телефонии. _(гл. 2)_

**Передача в основной полосе частот (baseband)** — цифровая модуляция, при которой сигнал занимает частоты от 0 до некоторого максимума; характерна для проводных каналов. _(гл. 2)_

**Передача в полосе пропускания (passband)** — цифровая модуляция, при которой сигнал сдвинут в диапазон частот вокруг несущей; характерна для беспроводных и оптических каналов. _(гл. 2)_

**Полное внутреннее отражение** — физический эффект, удерживающий свет внутри оптоволокна: при угле падения на границу сред выше критического луч полностью отражается обратно, не выходя наружу. _(гл. 2)_

**Полоса пропускания (аналоговая / цифровая)** — аналоговая полоса пропускания (Гц) — ширина диапазона частот, пропускаемых каналом без сильного затухания; цифровая полоса пропускания (бит/с) — максимальная скорость передачи данных; величины связаны, но не тождественны. _(гл. 2)_

**PON (Passive Optical Network, пассивная оптическая сеть)** — архитектура FTTH без запитанного оборудования между оконечной станцией и зданиями: только пассивные оптические разделители/объединители сигнала. _(гл. 2)_

**POTS (Plain Old Telephone Service)** — обычная (аналоговая) телефонная связь; в ADSL — канал 0 частотного плана. _(гл. 2)_

**PSK (Phase Shift Keying)** — фазовая манипуляция: цифровые символы кодируются сдвигом фазы несущей (см. BPSK, QPSK). _(гл. 2)_

**PSTN (Public Switched Telephone Network)** — коммутируемая телефонная сеть общего пользования. _(гл. 2)_

**QAM (Quadrature Amplitude Modulation, квадратурная амплитудная модуляция)** — комбинированная модуляция амплитуды и фазы несущей; QAM-16 — 4 бита/символ, QAM-64 — 6 бит/символ; чем больше уровней, тем выше скорость, но тем чувствительнее к шуму. _(гл. 2)_

**QPSK (Quadrature Phase Shift Keying)** — квадратурная фазовая манипуляция: 4 состояния фазы несущей, 2 бита на символ. _(гл. 2)_

**Ranging (измерение дальности)** — процесс определения модемом (кабельным или PON) своего расстояния от оконечного оборудования по времени прихода ответа на тестовый пакет — нужен для точной синхронизации восходящей передачи. _(гл. 2)_

**Ряд Фурье** — разложение периодической функции в сумму синусов и косинусов кратных частот (гармоник); основа математического анализа сигналов. _(гл. 2)_

**Символ** — единица сигнала, соответствующая одному или нескольким битам данных при многоуровневой модуляции. _(гл. 2)_

**Скремблирование** — смешивание данных с псевдослучайной последовательностью («исключающее или») перед передачей для равномерного распределения энергии сигнала по спектру и облегчения синхронизации, без затрат дополнительной полосы. _(гл. 2)_

**SONET / SDH** — синхронный стандарт передачи данных по оптоволоконным магистралям с точностью часов 10⁻⁹; базовая скорость STS-1/OC-1 = 51,84 Мбит/с, вся иерархия скоростей кратна ей. _(гл. 2)_

**Солитон** — световой импульс специальной формы, устойчивый к дисперсии и способный распространяться по оптоволокну на тысячи километров без искажения. _(гл. 2)_

**STDM (Statistical Time Division Multiplexing)** — мультиплексирование со статистическим временны́м разделением: данные попадают в общий канал по фактическому спросу, а не по жёсткому расписанию; фактически другое название пакетной коммутации, не путать с TDM. _(гл. 2)_

**T1 / E1** — стандарты TDM-мультиплексирования голосовых каналов на магистралях: T1 (Северная Америка/Япония) — 24×8 бит + 1 служебный = 1,544 Мбит/с; E1 (остальной мир) — 32×8 бит = 2,048 Мбит/с. _(гл. 2)_

**TCM (Trellis-Coded Modulation, решётчатое кодирование)** — схема модуляции с добавлением контрольных бит для коррекции ошибок при плотных созвездиях сигнала (использовалась в телефонных модемах). _(гл. 2)_

**TDM (Time Division Multiplexing)** — временно́е уплотнение: пользователи по очереди получают весь канал целиком на фиксированный временной слот. _(гл. 2)_

**Транспондер** — блок аппаратуры спутника связи, настроенный на определённую часть спектра: принимает восходящий сигнал, усиливает и переизлучает его на другой частоте вниз («узкая труба»). _(гл. 2)_

**μ-закон (μ-law)** — стандарт компандирования при импульсно-кодовой модуляции, используемый в Северной Америке и Японии (см. также A-закон). _(гл. 2)_

**UMTS (Universal Mobile Telecommunications System)** — европейское название системы 3G на основе WCDMA. _(гл. 2)_

**UWB (Ultra-WideBand, ультраширокополосная связь)** — передача короткими импульсами по очень широкой полосе (минимум 500 МГц), устойчива к узкополосным помехам, применяется в персональных сетях (PAN) малого радиуса. _(гл. 2)_

**VSAT (Very Small Aperture Terminal)** — недорогой спутниковый терминал с антенной около 1 м, обычно работающий через наземный концентратор с более мощной антенной. _(гл. 2)_

**WCDMA (Wideband CDMA)** — широкополосная технология 3G на основе CDMA, техническая основа UMTS, продвинута компанией Ericsson. _(гл. 2)_

**WDM / DWDM (Wavelength-Division Multiplexing / Dense WDM)** — спектральное уплотнение: частный случай FDM на оптических частотах, несколько сигналов на разных длинах волн объединяются в одно волокно; при очень плотном размещении каналов — DWDM. _(гл. 2)_

**Частота среза** — граничная частота полосы пропускания канала, выше которой сигнал заметно ослабляется (по соглашению — теряет более 50% мощности). _(гл. 2)_

**Чип / элементарная последовательность (в CDMA)** — короткий период, на который делится битовый интервал в CDMA (чип), и уникальный код станции из m чипов (элементарная/чип-последовательность), используемый для кодового разделения каналов. _(гл. 2)_

---

**AAL5 (ATM Adaptation Layer 5)** — основной уровень адаптации ATM для пакетных данных: добавляет к пакету концевик с длиной и 4-байтным CRC плюс биты заполнения до кратности 48 байт, чтобы кадр без остатка делился на ячейки ATM. _(гл. 3)_

**ACK / NAK (Acknowledgement / Negative Acknowledgement)** — управляющий кадр канального уровня: ACK — положительное подтверждение («кадр получен корректно»), NAK — отрицательное подтверждение («с кадром что-то не так, нужна повторная передача»). _(гл. 3)_

**ARQ (Automatic Repeat reQuest, автоматический запрос повторной передачи)** — зонтичный термин для протоколов, обеспечивающих надёжность через комбинацию подтверждений и повторной передачи по таймауту; частный случай — PAR. _(гл. 3)_

**ATM (Asynchronous Transfer Mode)** — ориентированный на соединение протокол канального уровня с передачей данных фиксированными 53-байтными ячейками (48 байт полезной нагрузки + 5 байт заголовка с идентификатором виртуального контура); применяется в ADSL (через AAL5/PPPoA) и телефонных WAN-каналах. _(гл. 3)_

**Битовое заполнение (bit stuffing)** — метод формирования кадра: после каждых пяти единиц подряд в потоке данных вставляется нулевой бит, снимаемый приёмником; гарантирует, что флаговая последовательность (01111110) встречается только на границах кадра; overhead ≈12,5%; используется в HDLC и USB. _(гл. 3)_

**Блочный код** — код с исправлением/обнаружением ошибок, в котором r контрольных бит вычисляются как функция от связанных с ними m бит данных (в противовес сверточному коду, работающему с непрерывным потоком). _(гл. 3)_

**BD (bandwidth-delay product, произведение полосы пропускания на задержку)** — число кадров, «умещающихся» в канале одновременно = полоса пропускания × время распространения сигнала в одну сторону; определяет минимальный размер окна (w ≥ 2BD+1) для полной загрузки канала при конвейерной передаче. _(гл. 3)_

**Виртуальный контур (virtual circuit, в ATM)** — идентификатор в заголовке ячейки ATM, определяющий маршрут ячейки внутри установленного соединения. _(гл. 3)_

**Go-Back-N (протокол с возвратом на n)** — протокол скользящего окна с конвейерной передачей: принимающее окно = 1 (кадры принимаются строго по порядку), при потере/повреждении кадра все последующие отбрасываются и впоследствии передаются повторно целиком; использует кумулятивное подтверждение; максимальный размер окна ≤ MAX_SEQ. _(гл. 3)_

**HDLC (High-level Data Link Control)** — исторический протокол канального уровня, для которого разработано битовое заполнение; флаг 01111110 (0x7E) на границах кадра. _(гл. 3)_

**Кадр (frame)** — единица данных канального уровня: пакет сетевого уровня, упакованный в заголовок (служебная информация) и концевик (контрольная сумма). _(гл. 3)_

**Канал со стиранием (erasure channel)** — модель ошибок, при которой физический уровень не искажает бит, а сообщает, что его значение потеряно (позиция ошибки известна) — исправлять такие ошибки проще, чем инверсию бита. _(гл. 3)_

**Код Хэмминга (Hamming code)** — систематический линейный блочный код с исправлением одиночных ошибок: контрольные биты стоят на позициях-степенях двойки, каждый проверяет чётность группы бит, чьи номера при разложении по степеням 2 включают позицию контрольного бита; при ошибке результаты проверок образуют синдром ошибки, указывающий на повреждённый бит. _(гл. 3)_

**Кодовая норма (code rate)** — доля неизбыточной информации в кодовом слове, m/n (m — биты данных, n — полная длина кодового слова); ≈1/2 для зашумлённых каналов, близка к 1 для хороших. _(гл. 3)_

**Кодовое слово (кодовая комбинация)** — n-битный блок, состоящий из m бит данных и r контрольных бит (n = m + r), используемый в кодах обнаружения/исправления ошибок. _(гл. 3)_

**Конвейерная обработка (pipelining)** — передача нескольких кадров подряд без ожидания подтверждения на каждый — необходима для эффективного использования канала при большом произведении полосы на задержку (BD). _(гл. 3)_

**Контрольная сумма (checksum)** — общее название для группы контрольных бит, вычисленных как сумма (в широком смысле) по сообщению; частные случаи — бит чётности, контрольная сумма Интернета (16-бит, дополнение до единицы), контрольная сумма Флетчера. _(гл. 3)_

**CRC (Cyclic Redundancy Check, циклический избыточный код / полиномиальный код)** — код обнаружения ошибок: кадр представляется многочленом, делится по модулю 2 на согласованный образующий многочлен G(x), остаток дописывается в кадр так, чтобы передаваемый кадр делился на G(x) нацело; ненулевой остаток при повторном делении на приёме = обнаруженная ошибка; наиболее надёжный и распространённый метод обнаружения ошибок на канальном уровне (CRC-32 в Ethernet, PPP). _(гл. 3)_

**Кумулятивное подтверждение (cumulative acknowledgement)** — подтверждение кадра с номером n, автоматически подразумевающее подтверждение всех более ранних неподтверждённых кадров; используется в Go-Back-N. _(гл. 3)_

**LCP (Link Control Protocol)** — протокол настройки соединения PPP: переговоры о параметрах (например, отказ от полей Address/Control, размер контрольной суммы) до начала передачи данных. _(гл. 3)_

**LDPC (Low-Density Parity Check, код с малой плотностью проверок на чётность)** — линейный блочный код с исправлением ошибок (Галлагер, 1962, переоткрыт в 1995): каждый выходной бит зависит от разреженного подмножества входных, декодируется итеративной аппроксимацией; хорош на больших блоках; применяется в цифровом ТВ, 10-гигабитном Ethernet, поздних версиях 802.11. _(гл. 3)_

**Линейный код (в контроле ошибок)** — код, в котором контрольные биты вычисляются как линейная функция от бит данных (обычно через XOR/сумму по модулю 2); не путать с линейным кодом физического уровня (глава 2, NRZ и др.). _(гл. 3)_

**MAX_SEQ** — максимальный порядковый номер кадра в протоколах скользящего окна (при поле номера n бит — MAX_SEQ = 2ⁿ−1); определяет допустимый максимальный размер окна. _(гл. 3)_

**NCP (Network Control Protocol)** — семейство протоколов настройки сетевого уровня в PPP, отдельный NCP для каждого поддерживаемого протокола сетевого уровня (IP и др.). _(гл. 3)_

**Образующий многочлен (generator polynomial), G(x)** — многочлен степени r, согласованный отправителем и получателем для вычисления CRC; старший и младший коэффициенты равны 1. _(гл. 3)_

**Однобитовый протокол скользящего окна** — протокол скользящего окна с максимальным размером окна 1 с обеих сторон, по сути двунаправленный stop-and-wait с пиггибекингом. _(гл. 3)_

**PAR (Positive Acknowledgement with Retransmission, положительное подтверждение с повторной передачей)** — протокол, в котором отправитель ждёт положительного подтверждения перед пересылкой следующего кадра и повторяет передачу по таймауту; частный случай ARQ. _(гл. 3)_

**Пиггибекинг (piggybacking)** — присоединение подтверждения к полю ack исходящего кадра с данными вместо отправки отдельного управляющего кадра; экономит накладные расходы на подтверждения. _(гл. 3)_

**Порядковый номер кадра (sequence number)** — номер в заголовке кадра, позволяющий получателю отличить новый кадр от повторно переданного дубликата. _(гл. 3)_

**PPP (Point-to-Point Protocol, протокол «точка-точка»)** — стандартный протокол канального уровня для двухточечных каналов Интернета (RFC 1661+): символьное заполнение, CRC для контроля ошибок, LCP/NCP для настройки соединения; применяется поверх SONET и (через ATM/AAL5, как PPPoA) поверх ADSL. _(гл. 3)_

**PPPoA (PPP over ATM)** — спецификация (RFC 2364), описывающая упаковку полей PPP «Протокол» и «Данные» внутрь кадра AAL5 при передаче по ATM (используется в ADSL); собственное кадрирование и CRC протокола PPP при этом не нужны. _(гл. 3)_

**Преамбула (preamble)** — фиксированный шаблон бит в начале кадра (например, 72 бита в 802.11), облегчающий приёмнику синхронизацию перед основным содержимым кадра. _(гл. 3)_

**Принимающее окно (receiving window)** — в протоколах скользящего окна: диапазон порядковых номеров кадров, которые получатель готов принять и буферизировать в данный момент. _(гл. 3)_

**Расстояние Хэмминга (кодовое расстояние)** — число бит, в которых различаются два кодовых слова (вычисляется как XOR слов и подсчёт единиц); минимальное кодовое расстояние кода определяет его способность обнаруживать (d+1) и исправлять (2d+1) ошибки. _(гл. 3)_

**Символьное заполнение (byte stuffing)** — метод формирования кадра: границы отмечаются флаговым байтом, случайно совпавшие с флагом или escape-символом байты внутри данных экранируются вставкой ESC перед ними; используется в PPP. _(гл. 3)_

**Синдром ошибки (error syndrome)** — набор результатов проверки контрольных бит кода Хэмминга при декодировании; ненулевой синдром, интерпретированный как число, указывает позицию повреждённого бита. _(гл. 3)_

**Систематический код** — код, в котором биты данных передаются напрямую, без перекодирования, вместе с отдельными контрольными битами (в противовес несистематическим кодам вроде сверточного кода NASA). _(гл. 3)_

**Скользящее окно (sliding window)** — семейство протоколов канального уровня, в которых отправитель и получатель одновременно работают с диапазоном (окном) допустимых порядковых номеров кадров; объединяет контроль ошибок (ARQ) и управление потоком в одном механизме; три варианта — однобитовый, Go-Back-N, Selective Repeat, различающиеся максимальным размером окна и стратегией обработки ошибок. _(гл. 3)_

**Размер окна** — максимальное число кадров, которые отправитель может выслать без подтверждения (или получатель — принять) в протоколах скользящего окна; для Go-Back-N ≤ MAX_SEQ, для Selective Repeat ≤ (MAX_SEQ+1)/2 — во избежание перекрытия окон при полном цикле потери и повтора. _(гл. 3)_

**Selective Repeat (протокол с выборочным повтором)** — протокол скользящего окна с конвейерной передачей: получатель буферизирует корректные кадры, пришедшие не по порядку, и запрашивает повторную передачу только конкретного потерянного/повреждённого кадра через NAK; требует индивидуальных таймеров и буферов на кадр, максимальный размер окна ≤ (MAX_SEQ+1)/2. _(гл. 3)_

**Сверточный код (convolutional code)** — код с исправлением ошибок, не относящийся к блочным: кодировщик обрабатывает непрерывный поток бит, выходной бит зависит от текущего и нескольких предыдущих входных бит (длина кодового ограничения); декодируется алгоритмом Витерби; пример — код NASA r=1/2, k=7 (Voyager, также 802.11). _(гл. 3)_

**Таймаут (timeout)** — интервал ожидания подтверждения, по истечении которого отправитель канального уровня считает кадр или его подтверждение потерянным и повторяет передачу. _(гл. 3)_

**Таймер (канального уровня)** — механизм, запускаемый при отправке кадра для отсчёта таймаута; в протоколах с конвейерной передачей может требоваться отдельный таймер на каждый неподтверждённый кадр. _(гл. 3)_

**Управление потоком с обратной связью (feedback-based flow control)** — получатель явно или неявно сообщает отправителю, сколько данных можно передать; основной подход канального уровня (в отличие от управления потоком с ограничением на транспортном уровне). _(гл. 3)_

**Управление потоком с ограничением (rate-based flow control)** — механизм, ограничивающий скорость отправителя без обратной связи от получателя; применяется только на транспортном уровне (глава 6). _(гл. 3)_

**Флаговый байт (FLAG)** — специальный байт (или битовая последовательность, например 0x7E), отмечающий начало и конец кадра при символьном/битовом заполнении. _(гл. 3)_

**Чередование (interleaving)** — техника преобразования кода, обнаруживающего/исправляющего изолированные ошибки, в код, обнаруживающий/исправляющий пакеты (последовательности) ошибок: контрольные биты вычисляются в ином порядке (например, по столбцам), чем передаются данные (по строкам). _(гл. 3)_

**Escape-символ (ESC)** — специальный байт, вставляемый перед случайно совпавшим с флагом или другим ESC байтом внутри кадра при символьном заполнении, чтобы отличить «настоящую» границу кадра от совпадения в данных. _(гл. 3)_

**Шеннона предел / формула Шеннона** — для канала с полосой B и отношением сигнал/шум S/N максимальная скорость передачи данных = B·log₂(1+S/N) бит/с; теоретический потолок при любом способе модуляции. _(гл. 2)_

---

**ACL (Asynchronous Connectionless)** — тип соединения Bluetooth для пакетных данных с максимальными усилиями (в отличие от SCO); максимум одно ACL-соединение на подчинённый узел, потерянные кадры пересылаются повторно. _(гл. 4)_

**Адаптация скорости (rate adaptation)** — понижение/повышение скорости передачи станцией 802.11 в зависимости от качества радиосигнала: слабый сигнал → более помехоустойчивая (и медленная) модуляция. _(гл. 4)_

**Адаптивная перестройка рабочей частоты (adaptive frequency hopping)** — техника Bluetooth: исключение из последовательности скачков частоты каналов, занятых другими радиосигналами (например, 802.11), для снижения взаимных помех. _(гл. 4)_

**AIFS (Arbitration InterFrame Space)** — межкадровый арбитражный интервал 802.11e: короче DIFS для приоритетного трафика (голос), длиннее DIFS для фонового трафика; задаёт приоритетность доступа к каналу. _(гл. 4)_

**ALOHA, чистая и дискретная (pure / slotted ALOHA)** — протоколы случайного доступа к общему каналу (Абрамсон, Гавайи, 1970-е): станция передаёт сразу (чистая) или только с началом такта (дискретная), при коллизии ждёт случайное время и повторяет; максимальная утилизация канала — 1/(2e)≈18% для чистой (при G=0,5) и 1/e≈37% для дискретной (при G=1); несущий протокол раздела 4.2, предок CSMA. _(гл. 4)_

**Ассоциация / реассоциация / дизассоциация (association / reassociation / disassociation)** — службы 802.11: подключение станции к точке доступа, смена точки доступа при перемещении, разрыв связи. _(гл. 4)_

**APSD (Automatic Power Save Delivery)** — механизм энергосбережения 802.11 (2005): точка доступа отдаёт буферизованный трафик сразу вслед за кадром от клиента, без ожидания следующего маяка; удобно для трафика с частым обменом в обе стороны (IP-телефония). _(гл. 4)_

**Аутентификация (authenticate, 802.11)** — обязательная процедура перед передачей данных через точку доступа; современная схема — WPA2 (AES), устаревшая — WEP. _(гл. 4)_

**Backscatter modulation / обратное рассеяние** — механизм передачи данных от пассивной RFID-метки к считывателю: метка не генерирует собственный радиосигнал, а модулирует отражение несущей, излучаемой считывателем. _(гл. 4)_

**Bluetooth Low Energy (BLE)** — режим Bluetooth (с версии 4.0, 2010) с отдельным энергоэффективным физическим/канальным уровнем для устройств с батарейным питанием (датчики, браслеты, маяки), в противовес классическому Bluetooth, ориентированному на непрерывные потоки (аудио). _(гл. 4)_

**Broadcast storm / широковещательный шторм** — ситуация, при которой неисправный или неверно сконфигурированный сетевой интерфейс генерирует поток кадров, прозрачно рассылаемый мостами всем станциям сети и забивающий всю пропускную способность и вычислительные ресурсы. _(гл. 4)_

**Бит-карта, протокол (basic bit-map method)** — бесконфликтный протокол доступа: период конкуренции из N однобитовых интервалов, где каждая станция сообщает бит готовности к передаче; после этого станции передают по порядку номеров без коллизий; пример протокола с резервированием. _(гл. 4)_

**Двоичная экспоненциальная выдержка (binary exponential backoff)** — алгоритм выбора паузы перед повторной передачей после коллизии: после i-й подряд коллизии пауза выбирается случайно из диапазона [0, 2^i−1] интервалов; диапазон фиксируется после 10 коллизий (на 1023), полная сдача — после 16; используется в классическом Ethernet, 802.11 (аналог) и в конкурентном сервисе 802.16. _(гл. 4)_

**Двоичный обратный отсчёт (binary countdown)** — бесконфликтный протокол доступа: станции одновременно передают свой адрес битами старший-к-младшему, логически складывая биты по ИЛИ на канале; станция с 0 в позиции, где суммарный бит стал 1, выбывает; побеждает станция с наибольшим адресом; эффективность до 100%, если адрес совпадает с первым полем кадра. _(гл. 4)_

**DCF / PCF (Distributed / Point Coordination Function)** — режимы координации доступа в 802.11: DCF — распределённая координация (все станции действуют независимо по CSMA/CA, основной режим), PCF — централизованная координация через точку доступа (не применяется на практике). _(гл. 4)_

**Домен коллизий (collision domain)** — множество станций, чьи одновременные передачи могут столкнуться друг с другом; на концентраторе — все подключённые станции, на коммутаторе — каждый порт свой домен коллизий. _(гл. 4)_

**EPC (Electronic Product Code)** — 96-битный уникальный идентификатор RFID-метки стандарта EPC Gen 2, электронная замена штрихкода. _(гл. 4)_

**Ethernet, кадр** — формат кадра классического/коммутируемого Ethernet: преамбула (8 байт), адрес получателя (6 байт, бит группового адреса), адрес отправителя (6 байт, включает OUI), поле Type/Length (2 байта), данные (46–1500 байт), наполнитель Pad, контрольная сумма CRC-32 (4 байта); минимальный размер кадра — 64 байта (из требования обнаружения коллизии за время 2τ). _(гл. 4)_

**Fast Ethernet (802.3u)** — стандарт Ethernet 100 Мбит/с (1995), тот же формат кадра и MAC-протокол, что и классический Ethernet, варианты кабелей 100Base-T4/TX/FX. _(гл. 4)_

**FDD (Frequency Division Duplex)** — дуплекс с частотным разделением: станция передаёт и принимает одновременно на разных поднесущих; альтернатива TDD в 802.16. _(гл. 4)_

**Frame bursting / пакетная передача кадров** — механизм Gigabit Ethernet: отправка нескольких кадров подряд одним «залпом» для эффективного использования канала в полудуплексном режиме, альтернатива расширению носителя. _(гл. 4)_

**Gigabit Ethernet (802.3ab)** — стандарт Ethernet 1000 Мбит/с (1999); полнодуплексный режим без CSMA/CD (через коммутатор) и полудуплексный с расширением носителя/пакетной передачей кадров (через концентратор); кабели 1000Base-SX/LX/CX/T; кодирование 8B/10B. _(гл. 4)_

**Джамбо-кадры (jumbo frames)** — кадры Ethernet длиной более 1500 байт (обычно до ~9 Кбайт), вне стандарта, но широко поддерживаются производителями; снижают частоту прерываний на гигабитных скоростях. _(гл. 4)_

**Домен широковещания / широковещательный домен (broadcast domain)** — множество станций, получающих один и тот же широковещательный кадр; VLAN ограничивает размер широковещательного домена независимо от физической топологии. _(гл. 4)_

**Засвеченная станция, проблема (exposed terminal problem)** — в беспроводных сетях: станция ошибочно воздерживается от передачи, услышав чужую передачу, которая на самом деле не создала бы помех в зоне её собственного получателя — впустую теряется пропускная способность. _(гл. 4)_

**LDPC в Ethernet** — код с малой плотностью проверок на чётность (см. гл. 3), применяется в 10-гигабитном Ethernet для коррекции ошибок на высоких скоростях без затрат на повторные передачи. _(гл. 4)_

**LLC (Logical Link Control)** — верхний подуровень канального уровня в семействе стандартов IEEE 802.x, скрывающий различия конкретных MAC-протоколов от сетевого уровня и определяющий, какому протоколу верхнего уровня передать данные кадра. _(гл. 4)_

**L2CAP (Logical Link Control and Adaptation Protocol)** — уровень стека Bluetooth над баseband-уровнем: сегментация/сборка пакетов до 64 Кбайт, мультиплексирование источников, контроль ошибок и качество обслуживания для ACL-трафика. _(гл. 4)_

**MACA (Multiple Access with Collision Avoidance)** — протокол беспроводного доступа (Карн, 1990): отправитель и получатель обмениваются короткими кадрами RTS/CTS перед передачей данных, чтобы предупредить соседние станции и избежать проблемы скрытой станции; предок механизма RTS/CTS в 802.11. _(гл. 4)_

**MIMO (Multiple Input Multiple Output)** — техника беспроводной связи с несколькими антеннами на приёмнике и передатчике для одновременной передачи нескольких потоков данных с последующим разделением на приёме; используется в 802.11n и далее, а также в 802.16. _(гл. 4)_

**Мост (bridge)** — устройство канального уровня, соединяющее несколько ЛВС: анализирует MAC-адрес назначения кадра и пересылает его только на нужный порт; современный синоним — коммутатор (switch). _(гл. 4)_

**Обучаемый мост (learning bridge)** — мост, автоматически строящий таблицу порт↔адрес по алгоритму противоточного обучения (backward learning): смотрит адрес отправителя каждого пришедшего кадра, чтобы узнать, через какой порт достижима эта станция; неизвестные адреса обрабатываются заливкой (flooding). _(гл. 4)_

**NAV (Network Allocation Vector)** — вектор распределения сети в 802.11: логический журнал занятости канала, который станция ведёт по полю «Длительность» услышанных кадров (виртуальное прослушивание канала, в дополнение к физическому). _(гл. 4)_

**OFDMA (Orthogonal Frequency Division Multiple Access)** — множественный доступ с ортогональным частотным разделением: разные поднесущие OFDM-канала назначаются одновременно разным станциям (в отличие от OFDM, где все поднесущие в момент времени использует одна станция); применяется в 802.16/WiMAX и в 802.11ax (Wi-Fi 6). _(гл. 4)_

**OUI (Organizationally Unique Identifier)** — первые 3 байта 48-битного MAC-адреса, централизованно назначаемые IEEE производителю сетевого оборудования блоками по 2²⁴ адресов. _(гл. 4)_

**Пикосеть (piconet)** — базовая единица сети Bluetooth: один главный узел (master) и до семи одновременно активных подчинённых узлов (slave); несколько пикосетей, связанных общим узлом, образуют скаттернет (scatternet). _(гл. 4)_

**Протоколы с ограниченной конкуренцией (limited-contention protocols)** — класс протоколов доступа, динамически регулирующих размер группы станций, состязающихся за конкретный интервал, объединяя малую задержку протоколов с конкуренцией при низкой загрузке и стабильную эффективность бесконфликтных протоколов при высокой; пример — протокол адаптивного прохода по дереву. _(гл. 4)_

**Протокол адаптивного прохода по дереву (adaptive tree walk protocol)** — протокол с ограниченной конкуренцией (Капетанакис, 1979): станции — листья двоичного дерева, при коллизии в интервал допускается только половина (поддерево) станций, и так до тех пор, пока в интервале не окажется 0 или 1 претендент; оптимальный уровень старта поиска i=log₂q при q готовых станциях. _(гл. 4)_

**Rate anomaly / аномалия скорости** — эффект в 802.11: без учёта эфирного времени станция с высокой скоростью передачи, конкурируя со станцией с низкой скоростью, замедляется примерно до уровня медленной станции, если обеим достаётся равное число кадров вместо равного эфирного времени; решается механизмом TXOP. _(гл. 4)_

**RFID, считыватель и метка (reader / tag)** — компоненты RFID-системы: считыватель — информационный центр с собственным питанием, метка — маломощное (обычно пассивное, без батареи) устройство с уникальным идентификатором, отвечающее на запросы считывателя. _(гл. 4)_

**RTS / CTS (Request To Send / Clear To Send)** — короткие управляющие кадры протокола MACA и его адаптации в 802.11: RTS запрашивает разрешение на передачу, CTS его подтверждает; соседи обеих сторон, услышав эти кадры, воздерживаются от передачи на время информационного обмена. _(гл. 4)_

**SCO (Synchronous Connection Oriented)** — тип соединения Bluetooth для трафика реального времени (голос): фиксированный слот в каждую сторону, до 3 SCO-каналов на подчинённый узел, кадры никогда не пересылаются повторно (вместо этого — прямая коррекция ошибок). _(гл. 4)_

**Скрытая станция, проблема (hidden terminal problem)** — в беспроводных сетях: станция не слышит передачу конкурента (слишком далеко) и ошибочно считает канал свободным, вызывая необнаружимую для себя коллизию у получателя. _(гл. 4)_

**Спанинг-три / связующее дерево (spanning tree), STP** — распределённый алгоритм построения бесциклового логического дерева поверх избыточной топологии мостов: выбор корня (мост с наименьшим MAC-адресом), построение дерева кратчайших путей до каждого моста, отключение портов вне кратчайшего пути; стандартизован как IEEE 802.1D; предотвращает бесконечную циркуляцию заливаемых кадров при петлях в топологии. _(гл. 4)_

**TDD (Time Division Duplex)** — дуплекс с временны́м разделением: станция чередует передачу и приём во времени на одной и той же частоте; предпочтителен в 802.16 при асимметричном трафике (нисходящий больше восходящего). _(гл. 4)_

**TXOP (Transmission Opportunity, возможность передачи)** — механизм QoS в 802.11: станции выделяется равное эфирное время, а не равное число кадров, что устраняет аномалию скорости для станций с разной скоростью передачи. _(гл. 4)_

**Устройства по уровням модели (repeater/hub/bridge/switch/router/gateway)** — несущая классификация сетевого оборудования по тому, до какого уровня стека поднимается обрабатываемая единица данных: повторитель и концентратор — физический уровень (аналоговый сигнал, без понятия кадра/адреса); мост/коммутатор — канальный уровень (MAC-адрес); маршрутизатор — сетевой уровень (сетевой адрес, например IP); транспортный шлюз — транспортный уровень; шлюз приложений — прикладной уровень (содержимое сообщения). _(гл. 4)_

**VLAN, тег 802.1Q** — 4-байтная вставка в заголовок кадра Ethernet между адресом отправителя и полем Type/Length: 2 байта Tag Protocol Identifier (0x8100) + 3 бита приоритета + 1 бит CFI + 12-битный VLAN ID; увеличивает максимальный размер кадра с 1518 до 1522 байт; старые сетевые карты интерпретируют 0x8100 как обычный (неизвестный) EtherType и не ломаются. _(гл. 4)_

**WPA3** — актуальная (на смену WPA2) схема защиты 802.11. _(гл. 4)_

**802.11ac / Wi-Fi 5** — ➕ стандарт беспроводных ЛВС (диапазон 5 ГГц, каналы шире, вплоть до 160 МГц, MU-MIMO, QAM высокого порядка), пришедший на смену 802.11n. _(гл. 4)_

**802.11ax / Wi-Fi 6, Wi-Fi 6E** — ➕ стандарт беспроводных ЛВС с OFDMA (та же идея, что в WiMAX), механизмом энергосбережения Target Wake Time; версия 6E добавляет диапазон 6 ГГц. _(гл. 4)_

**802.11be / Wi-Fi 7** — ➕ стандарт беспроводных ЛВС с одновременными множественными каналами связи (multi-link operation) и ещё более широкими каналами. _(гл. 4)_

**802.1Q** — стандарт IEEE (1998), вводящий тег VLAN в заголовок кадра Ethernet (см. VLAN, тег 802.1Q). _(гл. 4)_
